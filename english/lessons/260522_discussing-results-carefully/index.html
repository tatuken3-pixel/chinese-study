今日口に残す表現

  1. I’m not sure how to interpret them yet.
  2. Maybe we should say, “These data suggest,” rather than “These data show.”
  3. We need more data before drawing a firm conclusion.
01A
訳
今朝新しい結果を見たんだけど、まだどう解釈すればいいかはっきりしていない。
I looked at the new results this morning, but I’m not sure how to interpret them yet.
interpret the results：結果を解釈する
02B
訳
なるほど。予想していたパターンと違っているの？
I see. Is the pattern different from what you expected?
pattern：パターン、傾向
03A
訳
ある程度はそう。全体的な傾向はあるんだけど、1つの条件だけ違う動きをしている。
Kind of. The overall trend is there, but one condition behaves differently.
overall trend：全体的な傾向condition：条件
04B
訳
なるほど。主な傾向と例外を分けて考えた方がいいかも。
That makes sense. Maybe we should separate the main trend from the exception.
separate A from B：AとBを分けるexception：例外
05A
訳
それはいい指摘だね。一緒にしてしまうと、説明の筋がわかりにくくなる。
That’s a good point. If we mix them together, the story gets confusing.
the story gets confusing：説明の筋がわかりにくくなる
06B
訳
確信はないけど、まず例外を示して、その後なぜ重要なのかを説明するとよいかもしれない。
I’m not sure, but it might be useful to show the exception first and then explain why it matters.
it might be useful to...：〜すると有用かもしれないwhy it matters：なぜ重要なのか
07A
訳
言いたいことはわかる。そうすれば、扱いにくい部分を隠しているように見えないね。
I see what you mean. That way, it doesn’t look like we are hiding the awkward part.
awkward part：扱いにくい部分
08B
訳
そう。強く主張する代わりに、『この部分は追加検証が必要です』と言える。
Exactly. And we can say, “This part needs further testing,” instead of making a strong claim.
further testing：追加検証make a strong claim：強い主張をする
09A
訳
その言い方の方が安全に感じる。結果を言い過ぎたくない。
That wording feels safer. I don’t want to overstate the result.
wording：言い方、表現overstate：言い過ぎる、誇張する
10B
訳
そうだね。自信ありげに言いすぎずに、明確にすることはできる。
Right. We can be clear without sounding too confident.
be clear：明確であるsound too confident：自信過剰に聞こえる
11A
訳
『これらのデータは示している』ではなく、『示唆している』と言った方がいいかも。
Maybe we should say, “These data suggest,” rather than “These data show.”
suggest：示唆するshow：示す
12B
訳
賛成。suggest は不確実性の余地を残すから、この場合はより正確だと思う。
I agree. “Suggest” leaves room for uncertainty, which is more accurate here.
leave room for uncertainty：不確実性の余地を残すaccurate：正確な
13A
訳
もう1つの問題は、すべての反復をメインスライドに入れるべきかどうかだね。
Another question is whether we should include all the replicates in the main slide.
replicates：反復、リプリケートmain slide：メインスライド
14B
訳
メインスライドには要約を入れて、詳細な反復はバックアップに入れるかな。
I would include the summary in the main slide and put the detailed replicates in backup.
I would...：私なら〜するbackup：補足スライド
15A
訳
それは妥当だね。聴衆はたぶん最初に主なメッセージが必要だと思う。
That sounds reasonable. The audience probably needs the main message first.
reasonable：妥当なmain message：主なメッセージ
16B
訳
うん。誰かが聞いたら、バックアップを見せて詳細を説明できる。
Yes. If someone asks, you can show the backup and explain the details.
If someone asks：誰かが聞いたら
17A
訳
その構成に傾いている。よりシンプルで、より誠実に感じる。
I’m leaning toward that structure. It feels simpler and more honest.
I'm leaning toward...：〜に傾いているstructure：構成
18B
訳
それでいけると思う。ただ、限界点を明確に書いておくといい。
I think that works. Just make sure the limitation is stated clearly.
limitation：限界、制約state clearly：明確に述べる
19A
訳
いいね。確かな結論を出す前に、さらにデータが必要だという文を1つ入れるよ。
Good idea. I’ll add one sentence saying that we need more data before drawing a firm conclusion.
draw a firm conclusion：確かな結論を出す
20B
訳
その方が議論は弱くなるんじゃなくて、むしろ強くなると思う。
That would make the discussion stronger, not weaker.
make the discussion stronger：議論を強くする
